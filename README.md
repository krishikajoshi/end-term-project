# 🚀 AI Study Companion

An AI-powered productivity and session tracking web application built using **React** and **Firebase**.
This app helps users track their study/work sessions, analyze performance through interactive dashboards, and receive smart insights to improve focus and efficiency.

---

## ✨ Key Features

### 📊 Session Tracking

* Log sessions with **title, category, duration, and focus level**
* Categories include: Work, Study, Health, Entertainment
* Real-time storage using **Firebase Firestore**
* Delete sessions functionality

### 📈 Analytics & Reports

* Total sessions, total time, and average focus
* Visual dashboards with:

  * Category-wise distribution
  * Session activity trends
* Clean and interactive UI

### 🤖 AI Study Companion

* Smart suggestions based on user activity
* Productivity improvement tips
* Personalized recommendations

### 🎯 Smart Goal Generator

* Generates daily study targets
* Helps maintain consistency and discipline

### 🌗 UI/UX Features

* Dark / Light mode toggle
* Modern dashboard layout (wide + responsive)
* Smooth user experience

---

## 🛠 Tech Stack

* **Frontend:** React.js
* **Backend & Database:** Firebase (Authentication + Firestore)
* **Styling:** CSS
* **Charts:** Chart libraries (for analytics)
